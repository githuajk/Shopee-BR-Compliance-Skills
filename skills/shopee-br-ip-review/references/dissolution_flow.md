## 1. 核心事实

> **IP 类账号冻结，只有品牌方撤诉才能解封。**
>
> 内部审批通过、整改完成、申诉成立 —— **都不等于解封**。

| 处置来源 | 解封条件 |
|---|---|
| 品牌方投诉 | **品牌方撤诉**（或出具同意函） |
| 监管机构（ANVISA 等） | 原机构书面同意 |
| 平台自行认定 | 平台撤销认定 |

## 2. 流程

```
IP 投诉 → 平台冻结账号/商品
   ↓
内部核实 → 确认侵权（或否认）
   ↓
若确认 → 联系品牌方/权利人 → 协商撤诉或取得授权
   ↓
取得撤诉证明/授权文件 → 提交平台
   ↓
平台恢复 → 记录实际恢复日期
```

## 3. 状态记录要求

案件必须区分两个状态：

| 字段 | 含义 |
|---|---|
| 内部审批状态 | 内部是否认定侵权、是否已处置 |
| **平台侧实际状态** | **账号/商品在平台侧是否真的恢复** |

> ⚠️ 原型的解冻逻辑只要求「案件关闭 + 人工审批」。这不足以证明解封。
> 本模块必须以**平台侧实际状态**为准。

## 4. 证据

| 证据 | 说明 |
|---|---|
| 撤诉证明 | 品牌方的书面撤诉/同意函 |
| 授权文件 | 若走授权途径 |
| 平台恢复截图/记录 | 证明实际恢复 |
