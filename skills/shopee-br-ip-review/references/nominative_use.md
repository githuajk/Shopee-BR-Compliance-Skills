## 1. 区分标准

| 要素 | 指示性使用（合法） | 混淆性使用（风险） |
|---|---|---|
| 目的 | 表明产品**用途/兼容/来源** | 借用品牌**吸引力** |
| 位置 | 必要且适度 | 显眼、突出 |
| 表述 | "兼容 `<Marca>` <型号>" | "`<Marca>` 原厂" / "官方授权"（无授权时） |
| 附加说明 | 有"非授权"说明更好 | 无 |
| 商标位置 | 非主导 | 主导 |

## 2. 合法表述样例

```
Compatível com <Marca> <Modelo>
适配 <Marca> <Modelo>
Peça de reposição para <Marca> <Modelo>
```

## 3. 高风险表述样例

```
<Marca> Original
<Marca> Oficial
<Marca> Certificado
复制 <Marca> 包装 / <Marca> style
```

## 4. 判定流程

```
检测到品牌词
  ↓
判断上下文：是「兼容性/用途」还是「品质/来源」？
  ↓
用途 → 指示性使用 → `verdict = PASS`（或 info 风险 + 提示需标注"非授权"）
来源/品质 → 混淆性使用 → `confidence = signal` + 人工复核
```

## 5. 特别注意

> 指示性使用**合法不等于可以随便写**。使用他人标记时仍应：
> - 以必要限度为限
> - 不使消费者误以为存在授权关系
> - 在能说明时注明"非授权配件"
