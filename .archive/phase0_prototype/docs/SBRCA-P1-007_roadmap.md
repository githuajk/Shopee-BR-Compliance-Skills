## 1. 闸门原则

```
阶段交付 → 提交阶段报告 + 待审批事项 → 用户确认 → 进入下一阶段
```

**未获确认不得推进。** 阶段内可自主推进的判定标准：该项是否属于已确认需求、是否影响已确认的数据格式/接口/权限模型/架构（影响则需先做影响分析）。
