## 附：常见退回原因

| 退回原因 | 修复 |
|---|---|
| 改了白名单外的文件 | 撤销越界改动，在 §12.5 说明 |
| 测试未执行或只贴摘要 | 实际执行并贴完整输出 |
| 引用了不存在于抓取件的引文 | 改为 `unverified` 或补抓取件 |
| SKILL.md 缺要素 | 按 §9 七要素补齐 |
| 依赖其他模块的运行时产物 | 改用契约表达依赖 |
| 假设 Skill 自动调用 | 改为显式工作流描述 |
| 用了 YAML/CSV 作内部数据源 | 转为 JSON/MD |
